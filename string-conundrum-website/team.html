5Team

Team

A two-person Honours project in the Department of Computer Science at the University of Cape Town, supervised by Aslam Safla. Hlomla Kuhlane developed the front end and Luvuyo Matomela developed the back end. Design, evaluation and writing were shared.

Back end

1Supervision

Supervisor

Aslam Safla

Department of Computer Science, University of Cape Town

Aslam Safla teaches first-year Computer Science at UCT and proposed the project after observing that marks drop when string concepts are introduced. The team met with him weekly, and he carried out an acceptance walkthrough of the deployed system on 10 September 2026.

2Collaboration

Work done together

The proposal assigned the following to both members jointly, and both final papers report the same three-cycle evaluation.

  • API contract definition
  • System architecture decisions
  • Integration testing
  • Firebase project setup
  • User role design
  • String concept module design
  • Exercise creation
  • Misconception identification
  • Usability and learning evaluation
  • Ethics application
  • Report writing and review
  • Weekly synchronisation meetings
